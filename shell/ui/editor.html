How to use UV mapping

  1. Select a volume: click any object in the list or viewport.
  2. Switch to Texture mode: open the Texture tab at the top.
  3. Import an image: click Import image in the Surface panel on the right.
  4. Pick a projection: Spherical for orbs, Box for cubes, Planar for flats, Cylindrical for tubes.
  5. Apply checker: toggle Apply checker pattern to spot stretches and seams.
  6. Tweak Scale/Ratio/Rotate: in Surface → Image Transform to align the texture where you want it.
